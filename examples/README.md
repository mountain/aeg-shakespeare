# Quickstart examples

These files are intentionally small, runnable entry points into the public package API.  They are not substitutes for the complete mathematical essays in `tests/classical/` and `tests/research/`.

- `quickstart.py` — literal ordered history, explicit rewriting, and A/M (Addition/Multiplication) resonance.
- `constraint_quickstart.py` — exact equality modulo an algebraic constraint ideal.
- `grammar_quickstart.py` — process-generated finite grammar and return-relation discovery from a seed.

For mathematical lineage and citations, follow the corresponding docs and tests rather than treating an example script as a proof.
