# Existing-test reference review

Before `v0.0.1`, review each substantial file in `tests/classical/` and `tests/research/` for:

- a complete module-level mathematical essay;
- explicit primitive inputs and forbidden answer leakage;
- a precise calibration statement;
- an assertion-by-assertion proof map;
- classical lineage separated from Shakespeare interpretation;
- references for constrained mechanics / elliptic or hyperelliptic geometry / symbolic ideal methods as applicable;
- a clear boundary saying what the current test does not prove.

The review should prefer improving a few canonical calibrations to adding more examples.
