# Abel--Jacobi as a history quotient

The global-history line has now reached a point where the classical Abel--Jacobi construction can be introduced without being preloaded as a named solver.

The prerequisites are already executable:

```text
process quotient
  -> algebraic curve
  -> holomorphic differential basis
  -> square-root history lift
  -> closed cycles
  -> intersection pairing
  -> symplectic cycle presentation
  -> A/B period blocks
  -> normalized period matrix tau.
```

For a genus-\(g\) curve with holomorphic basis \(\omega_1,\ldots,\omega_g\), a lifted path \(\gamma\) carries the raw Abelian-integral increment

\[
u(\gamma)=\left(\int_\gamma\omega_1,\ldots,\int_\gamma\omega_g\right)\in\mathbb C^g.
\]

If \(A\) is the measured A-period block, Shakespeare normalizes the history coordinate by

\[
\widehat u(\gamma)=A^{-1}u(\gamma).
\]

For the same symplectic cycles used to form the period matrix,

\[
\widehat u(a_j)=e_j,
\qquad
\widehat u(b_j)=\tau_{\cdot j}.
\]

Therefore every closed integral combination of those histories acts by

\[
\widehat u\longmapsto \widehat u+m+\tau n,
\qquad m,n\in\mathbb Z^g.
\]

The corresponding normalized period quotient is

\[
\boxed{\mathbb C^g/(\mathbb Z^g+\tau\mathbb Z^g).}
\]

Classically, for a compact Riemann surface with a genuine symplectic homology basis and valid period data, this is the analytic presentation of its Jacobian. See Farkas--Kra, Forster, and Mumford in `REFERENCES.md`.

## Why Shakespeare keeps the history increment first

The ordinary Abel--Jacobi map fixes a base point \(P_0\) and sends a point \(P\) to the integrals

\[
\left(\int_{P_0}^{P}\omega_1,\ldots,\int_{P_0}^{P}\omega_g\right)
\pmod{\Lambda}.
\]

Before quotienting by the period lattice, this expression depends on the path from \(P_0\) to \(P\). Classical theory resolves that dependence by observing that two paths differ by a closed cycle, whose integral lies in the period lattice.

For Shakespeare this dependence is not a nuisance to hide prematurely. It is the process-history information we have been tracking from the beginning. Thus the first public object is an **Abel--Jacobi history increment**:

```text
lifted path
    -> vector of differential integrals
    -> A-normalized history increment.
```

Only afterwards does the normalized Abelian torus identify increments differing by declared closed-history shifts.

This gives a precise executable form of the principle

\[
\boxed{\text{state return} \neq \text{history return}.}
\]

A closed geometric history may return to its starting point while changing the lifted integral coordinate by a nonzero lattice vector. The period lattice is exactly the residual group generated by such globally closed histories.

## Why the object is not called `Jacobian`

`NormalizedAbelianTorus` is intentionally conservative terminology. At the current stage Shakespeare has:

- canonical holomorphic differentials for hyperelliptic quotients;
- sampled analytic continuation on the double cover;
- branch-generated symplectic cycles in a restricted real-split case;
- sampled intersection certificates;
- numerical A/B period blocks;
- symmetry and positive-definiteness checks for the normalized period matrix;
- the quotient lattice \(\mathbb Z^g+\tau\mathbb Z^g\).

It does **not** yet have:

- divisor-class arithmetic;
- an algebraic group model of the Jacobian;
- theta functions;
- the principal polarization as an independent exact object;
- Jacobi inversion;
- a general certified homology engine for arbitrary complex branch loci.

Calling the current object a normalized Abelian torus keeps the classical identification available as a shadow without making those unimplemented structures disappear linguistically.

## Genus-two executable calibration

`tests/research/test_abel_jacobi_history_quotient.py` starts from the same real-split curve

\[
y^2=(x^2-1)(x^2-4)(x^2-9).
\]

The branch-cut layer generates the A/B histories, the intersection layer verifies the symplectic form, and the period layer produces a passing Riemann profile. Only then is the torus object constructed.

The test then reintegrates each generated closed history and verifies

```text
A1 -> (1,0)
A2 -> (0,1)
B1 -> first column of tau
B2 -> second column of tau.
```

This is simple algebraically, but conceptually it closes a major gap in the process-first reconstruction:

\[
\boxed{
\text{branch geometry}
\to\text{closed history grammar}
\to\text{period residuals}
\to\text{normalized history space}
\to\text{period-lattice quotient}.
}
\]

## Current boundary

The current API can verify a caller-declared lattice shift \(m+\tau n\); it does not solve an arbitrary period-lattice recognition or nearest-lattice problem. More importantly, it still exposes path increments rather than a fully path-independent map from points or divisors. A later point/divisor layer should be introduced only when a real calibration requires it--most naturally Jacobi inversion or a dynamical problem whose process becomes translation on the Abelian torus.
