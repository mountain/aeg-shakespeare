# What the first public release is

AEG Shakespeare `0.0.1` should be understood as an **executable mathematical notebook in package form**.

The package side matters: abstractions are reusable, imports are stable enough for experimentation, distributions are tested, and named examples do not leak into `src/` as solvers.

The notebook side matters equally: the mathematical argument for a substantial calibration lives next to its executable checks, includes scholarly references, and distinguishes established mathematics from Shakespeare's process-first reinterpretation.

The first release is therefore not merely a code drop and not merely a collection of research notes.  Its intended unit of mathematical communication is:

```text
cited mathematical vignette
    + reusable public machinery
    + executable certificate
```
