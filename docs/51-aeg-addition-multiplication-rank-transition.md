# AEG Addition -> Multiplication: the Second Rank Transition

**Status:** research calibration of the second arithmetic rank transition. This note refines the meaning of V2--V4 in `THEORY_MAP.md`; it proposes no generic `Objectification`, `ProcessRank`, or `RankLowering` API.

## 0. Purpose

`50-aeg-translation-objectification-rank-lowering.md` established the first complete vertical calibration:

\[
\text{signed unit histories}
\to
\text{Translation objects }T_a
\to
\text{free Translation language}
\to
\text{compositional lowering}.
\]

That step is deliberately simple. After objectification, all semantics still live inside one abelian translation group.

The next arithmetic step is qualitatively different:

\[
\boxed{
\text{Addition / Translation}
\longrightarrow
\text{Multiplication / Dilation}.
}
\]

This transition must answer three questions that the first calibration did not force.

1. **What lower-rank Addition process is actually objectified by a Multiplication object?**
2. **What is the correct lower semantic target of a free multiplicative language?**
3. **How is the cross relation between Addition and Multiplication preserved by lowering?**

The executable essay `tests/research/test_aeg_addition_multiplication_rank_transition.py` answers all three in the smallest exact discrete AEG model.

The central result is:

> Multiplication does not objectify one long additive composite. It objectifies a **uniform endomorphism of the Translation process**. Consequently, its lowering target is not the set of Translation objects alone, but the action/endomorphism structure generated by Translation and Dilation. The resulting mixed semantics is the positive affine monoid, and the AEG relation
>
> \[
> D_kT_a=T_{ka}D_k
> \]
>
> is the defining cross-rank relation.

This is the first rank transition in the repository where lowering must preserve a genuinely noncommutative interaction between two arithmetic process directions.

---

## 1. Rank-one carrier: Translation objects

After the first calibration, the semantic Addition objects are

\[
\mathcal T=\{T_a:a\in\mathbb Z\},
\qquad
T_a(x)=x+a,
\]

with composition

\[
T_aT_b=T_{a+b}.
\]

Thus

\[
\mathcal T\cong(\mathbb Z,+).
\]

A Translation object has already forgotten the particular signed-successor history that constructed it. It is a stable semantic object at the new rank.

The question is now what kind of Addition process is stable enough to become a Multiplication primitive.

---

## 2. The tempting answer is wrong: a fixed repeated sum is still only Addition

Suppose one takes a particular Translation object and repeats it:

\[
T_a^k=T_{ka}.
\]

If objectification records only the output of this one composite, nothing new has happened. The result is again a Translation object.

For example,

\[
T_2^3=T_6,
\qquad
T_3^2=T_6.
\]

The same endpoint can arise from two different multiplication candidates. Looking only at the fixed output \(T_6\) cannot distinguish multiplication by three from multiplication by two.

But their behavior on another Translation object does distinguish them:

\[
T_1^3=T_3,
\qquad
T_1^2=T_2.
\]

Therefore the objectified semantic content cannot be

\[
\text{one repeated additive result}.
\]

It must retain the **uniform process acting on arbitrary Translation objects**.

---

## 3. What Multiplication objectifies

For every positive integer \(k\), define the repeated-Addition schema

\[
R_k:\mathcal T\to\mathcal T,
\qquad
R_k(T_a)=T_a^k=T_{ka}.
\]

This is an endomorphism of the Translation monoid:

\[
R_k(T_aT_b)
=
T_{k(a+b)}
=
T_{ka}T_{kb}
=
R_k(T_a)R_k(T_b).
\]

The second objectification step is therefore

\[
\boxed{
\operatorname{Obj}(R_k)=D_k,
}
\]

where \(D_k\) is the multiplicative/dilation primitive whose lower meaning is

\[
D_k:T_a\longmapsto T_{ka}.
\]

This answers the first question.

### 3.1 The important refinement of V2

The first Translation calibration could be described as objectifying a stable semantic **class of histories**.

The Multiplication calibration is stronger. Its new primitive objectifies a stable semantic **process on the lower-rank semantic carrier**.

Schematically, the candidate domain for objectification has moved from

\[
\mathcal C_r
\]

toward structures such as

\[
\operatorname{End}(\mathcal C_r),
\qquad
\operatorname{Act}(\mathcal C_r),
\qquad
\text{or other stable lower-rank process families}.
\]

This should be treated as **refinement pressure on the theory**, not as permission to introduce a generic endomorphism/objectification API. More independent rank transitions are needed before the correct abstraction is known.

But the arithmetic example already rules out one overly narrow reading:

> V2 cannot mean only “promote one point/equivalence class of the lower semantic quotient.”

A higher-rank primitive may instead objectify a reusable law of motion or action on lower-rank objects.

## 4. The pure multiplicative language

Let a bounded experiment retain some multiplicative primitives such as

\[
D_2,\quad D_3,\quad D_5.
\]

The rank-two multiplicative language is initially free:

\[
\mathcal H_\times=\mathsf F(\{D_k\}).
\]

A word

\[
D_{k_1}D_{k_2}\cdots D_{k_m}
\]

acts on Translation objects by

\[
T_a\longmapsto T_{(\prod_i k_i)a}.
\]

Thus an unseen multiplicative object such as multiplication by six is already generated by

\[
D_2D_3.
\]

The lower semantic target is naturally

\[
\boxed{
\operatorname{End}(\mathcal T),
}
\]

or the positive-integer scaling submonoid of that endomorphism monoid:

\[
\phi_k(T_a)=T_{ka}.
\]

The pure lowering map is

\[
L_\times(D_{k_1}\cdots D_{k_m})
=
\phi_{\prod_i k_i}.
\]

It preserves free composition:

\[
L_\times(H_1H_2)
=
L_\times(H_1)\circ L_\times(H_2)
\]

with the chronological/function-composition convention made explicit in the executable essay.

This answers the second question for the pure multiplicative fragment.

---

## 5. Why lowering cannot return only a Translation object

For \(k\ne1\), dilation

\[
D_k(x)=kx
\]

cannot equal any fixed translation

\[
T_b(x)=x+b.
\]

Indeed, equality at \(x=0\) would force

\[
b=0,
\]

but then equality at \(x=1\) would require

\[
1=k,
\]

contradicting \(k\ne1\).

Therefore the rank-one semantic set

\[
\mathcal T
\]

is too small as a target for the second rank lowering.

This is exactly the situation anticipated in `docs/44`: the lower target may need to be an explicitly enlarged semantic completion

\[
\widehat{\mathcal C}_1.
\]

Here the minimal natural completion is not mysterious. It is the action structure generated by Translations and their positive dilation endomorphisms.

---

## 6. Mixed Addition/Multiplication semantics: the affine monoid

To preserve the cross relation, the executable calibration admits mixed words generated by

\[
\{T_a\}\cup\{D_k\}.
\]

Their state semantics is generated by

\[
T_a(x)=x+a,
\qquad
D_k(x)=kx.
\]

Every mixed word lowers to an affine action

\[
\boxed{
x\longmapsto kx+b,}
\]

with

\[
k\in\mathbb N_{>0},
\qquad
b\in\mathbb Z.
\]

Thus the appropriate lower semantic completion is the positive affine monoid

\[
\boxed{
\operatorname{Aff}_+(\mathbb Z)
\cong
\mathbb Z\rtimes\mathbb N_{>0},
}
\]

where \(k\) acts on \(\mathbb Z\) by

\[
a\mapsto ka.
\]

Writing the normal form as

\[
T_bD_k,
\]

composition gives

\[
(T_bD_k)(T_cD_\ell)
=
T_{b+kc}D_{k\ell}.
\]

Equivalently, on pairs

\[
(b,k)(c,\ell)
=
(b+kc,k\ell).
\]

This is no longer an abelian group of translations. The second rank transition has forced a semidirect-product geometry.

---

## 7. The decisive cross relation

The finite Addition/Multiplication interaction is

\[
\boxed{
D_kT_a=T_{ka}D_k.
}
\]

Both sides act on a state \(x\) as

\[
k(x+a)=kx+ka.
\]

This relation is stronger than the internal laws

\[
T_aT_b=T_{a+b}
\]

and

\[
D_kD_\ell=D_{k\ell}.
\]

It says that Multiplication reorganizes the Addition geometry by an action

\[
\phi_k(a)=ka.
\]

The executable calibration checks all three relation families:

1. **Addition:** \(T_aT_b\equiv T_{a+b}\);
2. **Multiplication:** \(D_kD_\ell\equiv D_{k\ell}\);
3. **cross rank:** \(D_kT_a\equiv T_{ka}D_k\).

All are required to remain equal after lowering to the affine semantic target.

This is the first repository calibration where V4 relation soundness is not merely internal to one commutative operation.

---

## 8. Compositional lowering on arbitrary mixed words

The executable lowering does not special-case the three displayed relations. It interprets every legal finite mixed word.

Let

\[
L_{A/M}:\mathsf F(\{T_a,D_k\})
\longrightarrow
\operatorname{Aff}_+(\mathbb Z).
\]

Then

\[
L_{A/M}(T_a)(x)=x+a,
\]

\[
L_{A/M}(D_k)(x)=kx,
\]

and for arbitrary words

\[
\boxed{
L_{A/M}(H_1H_2)
=
L_{A/M}(H_1)\star L_{A/M}(H_2),
}
\]

where \(\star\) is chronological affine composition.

The test exhaustively checks all mixed words through a bounded depth over a small alphabet and compares the affine normal form against literal step-by-step execution on several initial states.

The bounded sweep is an executable calibration. The mathematical reason it succeeds is the closure of affine maps under composition.

## 9. What the second transition changes theoretically

The first Translation calibration might have encouraged an overly simple picture:

```text
stable lower history class
    -> new primitive
    -> free word language
    -> lower to old word semantics
```

The Multiplication calibration shows that the general shape must be wider:

```text
lower-rank semantic objects
    -> stable process/action on those objects
    -> objectified higher primitive
    -> free higher composition
    -> lower to an action/endomorphism completion
    -> preserve mixed relations with the lower rank
```

Three consequences follow.

### 9.1 Rank raising can objectify actions, not only values

A semantic process family may be the correct objectification candidate.

### 9.2 The lower target may need categorical/algebraic closure

A higher primitive may not be an element of the old semantic carrier but can still be completely grounded as an endomorphism or action on it.

### 9.3 Cross-rank relations are part of the semantics

A higher-rank language cannot be studied in isolation if its meaning is defined by how it transforms lower-rank objects.

These are substantive refinements of V2--V4, not API requirements yet.

Thus

\[

## 11. What remains before V5 analytic closure can be claimed

The second rank transition finally makes the analytic question well posed.

We now have:

- an explicit lower semantic carrier for Addition;
- an explicit Multiplication object as an action on that carrier;
- a free multiplicative language;
- a mixed Addition/Multiplication language;
- a compositional lowering target;
- the exact finite cross relation;
- an existing continuous A/M differential calculus.

The missing object is a comparison of **variation data across the explicit rank boundary**.

The target should have the form

\[
\boxed{
D_{\mathrm{low}}\circ L
\stackrel{?}{=}
\Lambda\circ D_{\mathrm{high}},
}
\]

or a more accurate noncommutative/connection-valued replacement.

A concrete next experiment should therefore define a smooth higher-rank dilation parameter and ask:

1. what is the tangent/variation object of the multiplicative process language?
2. how does lowering push that variation into the A/M frame?
3. is the comparison map \(\Lambda\) canonical?
4. does the semidirect relation force connection or adjoint terms rather than naive derivative commutation?
5. where does the first red team to analytic closure occur?

Only after those questions are executable should V5 move beyond research hypothesis.

## 12. Boundary choices in this calibration

### Positive factors only

The research essay uses

\[
k\in\mathbb N_{>0}
\]

because these embed directly into the AEG continuous dilation branch

\[
k=e^s>0.
\]

Multiplication by zero, sign reversal, rational scaling, and real/complex dilation are legitimate later extensions, but each changes algebraic properties and should not be silently bundled into the first calibration.

### Exact integer translations

Translations use \(a\in\mathbb Z\) so that the complete rank transition can be checked exactly without numerical tolerance.

### No generic API

All new semantic carriers remain inside the research executable essay. One arithmetic transition is evidence for the theory, not evidence that the correct general software abstraction has been discovered.

**Maturity:** concrete AEG research calibration.

**Semantic claim:** a positive-integer Multiplication object is the objectification of a uniform repeated-Addition endomorphism \(R_k(T_a)=T_{ka}\); pure multiplicative words lower to Translation endomorphisms; mixed A/M words lower compositionally to \(\operatorname{Aff}_+(\mathbb Z)\); Addition, Multiplication, and cross-rank relations lower soundly.

## 14. Result

The second arithmetic rank transition can now be stated cleanly:

\[
\boxed{
\begin{aligned}
\text{Addition objects:}&\quad T_a,\\
\text{objectified Addition process:}&\quad R_k:T_a\mapsto T_{ka},\\
\text{Multiplication object:}&\quad D_k=\operatorname{Obj}(R_k),\\
\text{pure lowering target:}&\quad \operatorname{End}(\mathcal T),\\
\text{mixed lowering target:}&\quad \operatorname{Aff}_+(\mathbb Z),\\
\text{cross relation:}&\quad D_kT_a=T_{ka}D_k.
\end{aligned}
}
\]

The main conceptual gain is not the familiar arithmetic identity itself. It is the executable identification of **what changes ontology between ranks**:

> Multiplication is a reusable objectification of a process acting on Addition objects.

That is the first place where the vertical Process Geometry tower becomes genuinely more than repeated compression inside one operation.
