# Citation-key conventions

Use short, readable keys in test essays.

Preferred forms:

- `[Author-Year]` for books and papers, e.g. `[Arnold-1989]`;
- `[DLMF-23.2]` for stable institutional reference sections;
- `[OriginalAuthor-Year]` when an original historical work is actually consulted.

A citation key should resolve either in the module docstring itself or in `docs/REFERENCES.md`.  If the test relies on a narrower locator than the shared bibliography provides, state that chapter/section/theorem in the test.

Do not cite a search-engine result, an uncitable snippet, or an informal paraphrase when a standard monograph, primary paper, DOI, arXiv identifier, or stable institutional source is available.
