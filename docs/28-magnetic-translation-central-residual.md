# Magnetic translations: the second central-residual organism

**Status:** independent red-team calibration; no public API change yet.

## 1. Why this example matters

The Galilean sequence isolated a precise limitation of the frozen finite-family API:

\[
\text{visible family action}
\to
\text{ordinary character pullback}
\]

cannot create the affine mass-dependent shift required by the full free-particle response.  In a Hamiltonian realization the missing information reappears as

\[
\{K,P\}=m,
\]

a nonzero central generator residual whose Hamiltonian vector field is zero.

That is strong evidence, but Galilean II and III are still two views of the same physical system.  Before promoting a `ProcessCocycle` or `CentralResidual` abstraction, Shakespeare needs an independent organism.

Uniform-field magnetic translations provide exactly that test.

## 2. Visible process law

Let planar translation parameters be

\[
a=(a_x,a_y)\in\mathbb R^2.
\]

The visible translation family remains ordinary addition:

\[
T_aT_b\rightsquigarrow T_{a+b}.
\]

This is already represented by the frozen `ProcessFamily` API.  Nothing about the visible parameter law itself requires a new abstraction.

## 3. A lifted phase/history realization

Fix a uniform perpendicular magnetic field and write

\[
\beta=qB.
\]

For one symmetric-gauge convention, augment the visible point \((x,y)\) by an additive phase/history coordinate \(\theta\), and define the lifted step

\[
\widetilde T_a:
(x,y,\theta)
\mapsto
\left(
 x+a_x,
 y+a_y,
 \theta+
 \frac{\beta}{2\hbar}(a_x y-a_y x)
\right).
\]

Then two successive lifted translations do not collapse exactly to the direct lifted translation by \(a+b\):

\[
\widetilde T_a\widetilde T_b
=
\omega(a,b)+\widetilde T_{a+b}
\]

in additive phase notation, with

\[
\boxed{
\omega(a,b)=
\frac{\beta}{2\hbar}(a\wedge b)
}
\]

and

\[
a\wedge b=a_xb_y-a_yb_x.
\]

In multiplicative phase notation the same statement becomes

\[
M_aM_b
=
\exp(i\omega(a,b))M_{a+b},
\]

up to the fixed active/passive and charge-sign convention.

The important point is not that convention-dependent sign.  It is that visible addition has acquired a central composition residual depending only on the oriented area / magnetic flux.

## 4. The residual satisfies the cocycle law

Associativity of the lifted composition requires

\[
\omega(a,b)+\omega(a+b,c)
=
\omega(b,c)+\omega(a,b+c).
\]

Because the wedge product is bilinear, the executable vignette verifies this identity exactly.

The two translation orders have the same visible endpoint, but their phase histories differ by

\[
\boxed{
\omega(a,b)-\omega(b,a)
=
\frac{\beta}{\hbar}(a\wedge b).
}
\]

Thus the ordered history retains precisely the flux through the oriented parallelogram even though the visible translation state forgets it.

This is especially close to Shakespeare's process/history philosophy:

\[
\boxed{
\text{visible state return}
\neq
\text{lifted history return}.
}
\]

## 5. Generator realization

In symmetric gauge, define mechanical momenta

\[
\pi_x=p_x+\frac{\beta}{2}y,
\qquad
\pi_y=p_y-\frac{\beta}{2}x,
\]

and

\[
H=\frac{\pi_x^2+\pi_y^2}{2m}.
\]

A convenient pair of magnetic-translation generators is

\[
K_x=p_x-\frac{\beta}{2}y,
\qquad
K_y=p_y+\frac{\beta}{2}x.
\]

The executable calibration verifies

\[
\{K_x,H\}=0,
\qquad
\{K_y,H\}=0,
\]

and the central relation

\[
\boxed{\{K_x,K_y\}=-\beta.}
\]

Yet \(-\beta\) is constant, hence

\[
X_{-\beta}=0.
\]

Therefore the finite canonical flows generated by \(K_x\) and \(K_y\) commute as visible phase-space maps even though their generator presentation retains the nonzero central bracket.

This is structurally the same phenomenon seen in Galilean mechanics.

## 6. Galilean versus magnetic translations

| Feature | Galilean free particle | Magnetic translations |
|---|---|---|
| visible process law | boost / translation action | planar translation addition |
| hidden scalar | mass \(m\) | magnetic coupling / flux \(qB\) |
| generator residual | \(\{K,P\}=m\) | \(\{K_x,K_y\}=-qB\) |
| residual vector field | zero | zero |
| finite visible action | loses central data | loses phase/flux history |
| finite lifted correction | affine momentum-energy shift | explicit area-dependent phase 2-cocycle |

The common pattern is now difficult to dismiss as an accident:

\[
\boxed{
\text{visible process composition}
+
\text{central information erased by visible semantics}.
}
\]

The difference is equally important.  Magnetic translations expose an explicit finite 2-cocycle immediately, while the Galilean line has so far exposed its finite correction as an affine response shift and its central structure most transparently at generator level.

Therefore the next abstraction should not simply copy the magnetic formula.

## 7. API consequence

The evidence threshold for a central-residual abstraction is now substantially stronger: two independent mechanical systems exhibit the same hidden-central-information pattern.

However, the exact public shape is still underdetermined.  At least three designs remain plausible:

1. a finite `FamilyCocycle` attached to process-family composition;
2. a more neutral `CentralResidual` that can live at finite or generator level;
3. a layered construction where finite cocycles and infinitesimal central brackets are two realizations of one extension object.

Shakespeare should not choose among these solely from terminology.  The next step should compare the Galilean and magnetic examples against the smallest candidate interfaces and choose the one that preserves both without forcing either into the other's representation.

## 8. Five-line research ledger

**Primitive assumptions.** Ordinary planar translations, uniform perpendicular magnetic field, one fixed symmetric-gauge realization, and canonical Poisson structure.

**Forbidden structures.** Predeclared magnetic translation group, projective representation, group cohomology, spectral decomposition, or public cocycle API.

**Discovered structure.** Ordinary visible translation addition, exact lifted flux 2-cocycle, nontrivial translation commutator phase, central generator bracket \(\{K_x,K_y\}=-qB\), and commuting visible canonical flows.

**New reusable abstraction.** None yet.

**Unresolved manual choice.** The minimal common public object that covers both Galilean mass and magnetic flux residuals without overfitting either example.
