# First-release reading path

A reader evaluating `0.0.1` should not start by scanning every exported symbol.  The intended path is:

1. `README.md` for the project question and quickstart;
2. `docs/00-process-presentation-v0.1.md` for the generic process-presentation object;
3. `docs/09-literate-programming-and-mathematical-lineage.md` for how to read the source;
4. `tests/classical/` for complete cited mathematical vignettes;
5. `docs/06-addition-multiplication-function-theory.md` for the first concrete process-generated function theory;
6. `tests/research/` for cross-problem comparisons whose theorem/interpretation/conjecture status is explicitly separated;
7. `docs/10-release-0.0.1.md` for the pre-alpha compatibility contract.

The package is an experimental mathematical instrument.  Its strongest claims are the exact certificates executed by the tests; broader interpretations are identified as such in the literate prose.
