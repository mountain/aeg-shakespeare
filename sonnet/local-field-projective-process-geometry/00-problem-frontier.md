# Phase 0 — local-field projective process frontier

**Status:** frozen initial contract; exact finite calibration in progress;
strong local-field unification unproved.

**Domains:** arithmetic histories, projective actions, continued fractions,
local fields, non-Archimedean topology, observer-relative canonicalization,
effective symbolic computation.

**Theory Map relation:** tests H0/H1/H2 and the cross-cutting unit/ruler and
effective-analysis constraints.  It makes no V2--V5 or API claim.

## 1. Why this is one problem rather than two imported subjects

The AEG bilateral calculation begins with a one-hole arithmetic history.  For
constants in a field \(K\), every nondegenerate elementary section has a
fractional-linear matrix.  Addition and Multiplication lie in the stabilizer
of infinity, while right-slot division supplies

\[
J(z)=-\frac1z.
\]

Translations, nonzero dilations, and \(J\) generate \(PGL_2(K)\).  A right
reciprocal update

\[
F_k(z)=a_k+\frac{b_k}{z},
\qquad
M_k=\begin{pmatrix}a_k&b_k\\1&0\end{pmatrix}
\]

therefore has three simultaneous finite readings:

1. a literal right-expanded arithmetic history;
2. a chronological projective matrix product \(M_n\cdots M_1\);
3. a generalized continued-fraction truncation whenever the affine
   denominators remain admissible.

That algebra is already available before a topology or completion is chosen.
The new primitive question is:

> Can one start with the same rational process language and derive its local
> geometry from the distinctions made by a declared place observer?

This order matters.  The real line, the \(p\)-adic line, the hyperbolic plane,
and the Bruhat--Tits tree are classical comparison objects and hidden oracles;
they are not admitted as the initial ontology of the experiment.

## 2. Problem-native primitive audit

### Primitive processes

The native grammar contains only:

- rational translation \(T_a:z\mapsto z+a\);
- nonzero rational dilation \(D_k:z\mapsto kz\);
- right reciprocal/inversion \(J_b:z\mapsto b/z\);
- chronological finite composition with literal operand-slot history.

The finite process carrier is `ProcessWord`.  Matrix multiplication is a
certified semantic lowering of these histories, not a replacement for their
literal order.

### Observer and task

Two observer families read the same rational endpoints:

\[
O_{\infty,\epsilon}(x,y): |x-y|_\infty<\epsilon,
\]

and, on \(p\)-integral data,

\[
O_{p,n}(x,y):x\equiv y\pmod {p^n}
\iff v_p(x-y)\ge n.
\]

Phase 0 tasks are exact:

1. preserve every declared finite residue observation;
2. preserve literal history before matrix lowering;
3. reconstruct the rational affine endpoint whenever ordinary evaluation is
   admissible;
4. transport the observer's scale under Addition, Multiplication, and Möbius
   action;
5. compare candidate digit sections under declared, noninterchangeable cost
   rulers.

### Forced symmetries and covariance

Addition is \(p\)-adically isometric:

\[
v_p((x+a)-(y+a))=v_p(x-y).
\]

Multiplication transports scale:

\[
v_p(kx-ky)=v_p(k)+v_p(x-y).
\]

For

\[
g(z)=\frac{Az+B}{Cz+D},
\qquad \Delta=AD-BC\ne0,
\]

the exact difference identity is

\[
g(x)-g(y)
=\frac{\Delta(x-y)}{(Cx+D)(Cy+D)},
\]

hence, away from poles,

\[
v_p(gx-gy)
=v_p(\Delta)+v_p(x-y)
-v_p(Cx+D)-v_p(Cy+D).
\]

This is the first candidate bridge from bilateral projective history to a
moving non-Archimedean ruler.  It is an exact covariance law, not yet a
generic observer connection.

## 3. Forbidden imported structures

Phase 0 must not:

1. call the residue-prefix tree the Bruhat--Tits tree;
2. choose one \(p\)-adic continued-fraction algorithm as canonical;
3. use a real floor map or order after changing to a \(p\)-adic observer;
4. infer a vertical arithmetic rank from an observation-resolution tower;
5. quotient literal histories merely because their projective endpoints
   agree;
6. infer a global scalar complexity from valuation depth alone;
7. create a `LocalField`, `BruhatTitsTree`, `ContinuedFraction`,
   `ValuationConnection`, or related framework API;
8. use floating-point agreement as evidence for an exact local-field claim.

## 4. Frozen hypotheses

### H-LF1 — observer-induced completion

The same rational process can have inequivalent task geometries under
\(|\cdot|_\infty\) and \(|\cdot|_p\).  Finite evidence must exhibit a fixed
history whose scale behavior reverses when only the observer changes.

### H-LF2 — exact refinement geometry

The equivalences modulo \(p^n\) form continuation-compatible nested
refinements for the declared integral Addition process.  Their inverse-limit
interpretation is classical; Phase 0 certifies only the finite tower.

### H-LF3 — projective scale transport

The Möbius denominator law is sufficient to treat local \(p\)-adic resolution
as a transported ruler on pole-free finite samples.  Curvature, holonomy, and
global canonical transport remain open.

### H-LF4 — continued fractions as compiled histories

Finite right-reciprocal expressions, recurrences, and matrix products commute
exactly.  A full coding claim additionally requires a digit selector,
admissible domain, convergence/failure semantics, and cost model.

### H-LF5 — canonicality is task-relative

Two digit sections may preserve identical finite residue semantics while
winning under different cost axes.  A globally preferred digit presentation
must therefore be proved from extra task or physical structure.

## 5. Kill and split conditions

The strong bridge must be weakened or split if:

- residue equivalence fails continuation stability for a claimed process
  alphabet;
- matrix lowering disagrees with ordinary admissible history evaluation;
- the proposed scale transport omits a pole or denominator valuation;
- a claimed canonical digit section changes when an equally legitimate cost
  ruler is used;
- the full lattice/coset construction later disagrees with the finite boundary
  refinement used here;
- a \(p\)-adic continued-fraction implementation lacks exact convergence or
  explicit nonconvergence semantics;
- the local-field presentation is symbolically or computationally worse than
  its declared baseline and the additional cost is hidden;
- suggestive real/\(p\)-adic parallelism supplies no new certificate,
  prediction, compression, or failure localization.

## 6. Classical controls and oracle firewall

The following sources are comparison controls, not proposal generators:

- Caroline Series identifies regular continued fractions with a symbolic
  coding of modular-surface geodesic flow;
- Bruhat and Tits, and Serre's exposition, construct the tree associated with
  \(PGL_2\) over a non-Archimedean local field;
- the \(p\)-adic continued-fraction literature contains multiple algorithms
  with materially different termination, convergence, and periodicity
  behavior.

Phase 0 may reproduce elementary consequences needed for certificates.  It
must not insert a literature-standard fundamental domain or digit algorithm
and then describe the imported object as discovered by Process Geometry.

## 7. First evidence gate

Gate 0 passes only if one seconds-scale exact test file certifies:

1. place-relative scale behavior of one fixed rational history;
2. nested finite residue quotients;
3. Addition/Multiplication ruler covariance;
4. affine versus inversion projective behavior;
5. right-reciprocal matrix lowering;
6. Möbius valuation transport;
7. one digit-section canonicalization defect.

Passing Gate 0 opens, but does not execute, full Bruhat--Tits reconstruction,
real geodesic coding, and competing \(p\)-adic continued-fraction phases.
