# Lonely Runner frontier audit for Sonnet 001

**Audit date:** 2026-08-22  
**Purpose:** freeze the problem statement, current fixed-dimensional frontier, accepted finite-reduction route, and the bottleneck relevant to Shakespeare before running new representation experiments.

## 1. Fixed-dimensional statement

For a positive integer tuple

\[
\mathbf u=(u_1,\ldots,u_k),
\]

write \(\|x\|\) for distance from \(x\) to the nearest integer.  The tuple has the LR property if some real \(t\) satisfies

\[
\|tu_i\|\ge \frac1{k+1}\quad\text{for every }i.
\]

`LRC(k)` is the assertion that every positive integer `k`-tuple has this property.  This is equivalent to the usual `k+1`-runner formulation after taking speeds relative to one runner.

## 2. Current frontier

Sungkawichai and Trakulthongchai prove, with computer assistance,

\[
LRC(k)\quad\text{for all }k\le 12.
\]

Their theorem therefore reaches **13 total runners**.  The next fixed-dimensional case is

\[
\boxed{LRC(13)\text{, i.e. 14 total runners}.}
\]

This audit treats `LRC(13)` as open.  Any future claim must re-check the literature before execution because this is an active computational frontier.

## 3. The finite-checking architecture

The relevant modern route has three layers.

### 3.1 Global finite bound

Malikiosis–Santos–Schymura prove a linearly exponential finite-checking theorem using the zonotopal formulation.  In the form used by the later computational work, if `LRC(k-1)` holds then a counterexample to `LRC(k)` must have bounded product of speeds.  This turns enough prime-divisibility certificates into a contradiction.

### 3.2 Modular ansatz

For prime \(p\) and positive integer \(l\), the later papers study residue tuples modulo \(lp\) together with witness times on the grid

\[
\frac1{lp}\mathbb Z.
\]

A tuple is `(k,p,l)`-proper if either:

- a specified gcd condition certifies reducibility; or
- it has a grid witness \(t\in\frac1{lp}\mathbb Z\) satisfying all loneliness inequalities.

Let \(I(k,p,l)\) denote the improper tuples.  Eventual properness modulo \(p\) is encoded by the set \(J(k,p)\) of residue tuples that survive every finite lift.

If \(J(k,p)=\varnothing\), then any global counterexample must have one speed divisible by \(p\).  Accumulating enough such primes forces the product of speeds above the independent finite bound and yields a contradiction.

### 3.3 Lifting and backward projection

The 2026 proof repeatedly applies two certified transformations to supersets of \(J(k,p)\):

```text
lift by c:
    refine a residue tuple from modulus lp to clp,
    then discard newly proper lifts

backward project:
    project survivors back to modulus p
```

The invariant is inclusion of the true difficult set under projection.  This is already naturally expressible as a sequence of task-relative presentation morphisms rather than as one monolithic solver.

## 4. Existing exact quotient

The implementation identifies tuples modulo \(p\) under the group generated by:

1. permutation of coordinates;
2. independent sign flips;
3. global multiplication by a unit of \(\mathbb Z_p\).

A canonical representative can therefore be chosen with

\[
1=v_1\le v_2\le\cdots\le v_k\le\frac{p-1}{2}.
\]

The authors estimate that this changes the initial search size from roughly

\[
p^k
\]

to

\[
\binom{p/2}{k-1}\approx\frac{p^k}{2^k(k-1)!}.
\]

They explicitly call this reduction essential.

This is a useful calibration for Shakespeare because the quotient is not merely syntactic: Proposition 5.1 proves that eventual properness is invariant under the generating actions.

## 5. The actual `k=13` bottleneck

The most important conclusion of this audit is negative: **the immediate frontier is not the lifting stage.**

The 2026 paper states in its concluding remarks that the primary bottleneck for extending the proof to `k=13` is efficient computation of

\[
I(k,p,1).
\]

The authors say that progress likely requires a better understanding of speed tuples with no witness in the ansatz, producing stronger pruning conditions for the initial sieve.

This gives Sonnet 001 a sharper target than a generic request for faster enumeration:

\[
\boxed{
\text{discover structure in the no-witness residue tuples before lifting begins.}
}
\]

For `k=13`, note also that `k+1=14=2\cdot7`; unlike the prime cases `k=10,12`, the special polynomial argument for the tight tuple is not the obvious first obstruction.  The paper itself points instead to the initial `find_cover`/`I(k,p,1)` computation.

## 6. Upstream executable baseline

The companion repository `vzsky/13-lonely-runners` separates the computation into three main components:

```text
find_cover   -> compute I(k,p,1)
lift         -> lifting and lifting strategy
main/driver  -> dispatch the proof computation
```

The repository reports that `main` contains polished code checked through `k <= 10`, while branch `for-k-12` is the earlier version used for `k=11,12` runs.

For Shakespeare, `find_cover` is therefore the first baseline to reconstruct and instrument.  We should not initially rewrite the entire proof stack.

## 7. Phase-0 exact semantics

Before representation search, we freeze two independent predicates.

### Continuous LR oracle

Given integer speeds, determine exactly whether

\[
\exists t\in\mathbb R:\quad
\min_i\|u_it\|\ge \frac1{k+1}.
\]

For small speeds this can be decided in exact rational arithmetic by checking the finite set of boundaries where one constraint satisfies

\[
\|u_it\|=\frac1{k+1}.
\]

If the feasible set is nonempty, it is a nonempty closed subset of the circle and, since `t=0` is infeasible, has a boundary point belonging to this finite set.  Hence boundary testing is exact, not sampling.

### Ansatz-grid oracle

Given `(k,p,l)` and a residue tuple, determine exactly whether a witness exists among

\[
t=\frac{a}{lp},\qquad a=0,\ldots,lp-1.
\]

Together with the gcd clause, this reproduces the exact local proper/improper semantics used by the finite proof.

These two predicates must remain independent: the first answers the mathematical instance; the second answers whether a particular finite presentation has already certified it.

## 8. Shakespeare questions after Phase 0

The first representation-search experiments should ask:

1. Which statistics of a partial speed tuple predict *future* properness under lift, rather than merely current lack of a witness?
2. Can two residue states be certified equivalent under all lifts in a bounded grammar without being equivalent under the known permutation/sign/unit group?
3. Can the initial depth-first search be factored through a smaller state graph whose nodes encode witness-deficit or arc-cover structure rather than labelled tuples?
4. Which candidate quotient fails on tight tuples or on deliberately constructed states whose current witness sets agree but whose lifted witness sets diverge?
5. Does a discovered quotient learned only from solved `k` transfer unchanged to `k=13`?

The crucial red-team principle is the same one already used elsewhere in Shakespeare:

> equality of current observations is insufficient; a valid quotient must preserve the declared task under allowed continuations.
